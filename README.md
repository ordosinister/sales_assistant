
# sales_assistant

Sales analysis assistant for SGE shipment data.
Supports two workflows:

1. **Deterministic Pipeline** (`workflow.py`) — fixed 5-sheet analysis with PDF export.
2. **AI Agent** (`run.py`) — LangChain ReAct agent with Ollama for flexible, natural-language-driven analysis.

---

## Project Structure

```
.
├── data/                          # Input / Output directory
│   ├── SGE*.xlsx                  # Raw sales data (input)
│   └── Sales_Report_*.pdf         # Final PDF reports (output)
├── config/
│   ├── analysis_requirements.txt  # Analysis goals for run.py
│   └── report_settings.json       # Output filename templates & paths
├── src/logic/
│   ├── 01_find_input.py           # Locate SGE*.xlsx in data/
│   ├── 02_generate_sheets.py      # Build analysis Excel (5 sheets)
│   ├── 03_generate_html.py        # Generate self-contained HTML report
│   └── 04_export_pdf.py           # Export HTML → PDF via Playwright
├── workflow.py                    # Main deterministic pipeline
├── run.py                         # AI agent entry point (LangChain + Ollama)
├── requirements.txt               # Python dependencies
└── setup.bat                      # Windows embedded-Python setup
```

## Setup

### Option A: Existing Python Environment

Ensure you have Python 3.14+ and install dependencies:

```bash
pip install -r requirements.txt
playwright install chromium
```

### Option B: Portable Embedded Python (Windows)

Run `setup.bat` to download and configure an isolated Python 3.14.7:

```batch
setup.bat
```

- Idempotent: skips download if `python\python.exe` already exists.
- Installs all dependencies from `requirements.txt`.
- Installs Playwright Chromium automatically.

## Usage

### Workflow 1 — Deterministic Pipeline (`workflow.py`)

Runs a fixed 5-step analysis and produces a styled PDF report.

```bash
python workflow.py <target_usd>
```

Example:

```bash
python workflow.py 1200000
```

**What it does:**

1. Finds `SGE*.xlsx` in `./data`.
2. Generates an analysis Excel with 5 sheets:
   - Revenue Achievement Rate
   - Year-over-Year Comparison
   - Top 5 End Customers
   - Top 5 Industries and End Customers
   - Product Category Summary
3. Builds a self-contained HTML report with Chart.js charts.
4. Exports the HTML to PDF via Playwright.
5. Cleans up intermediate files (`analysis_*.xlsx`, `report_*.html`).

**Options:**

- `--keep-temp` — Retain intermediate `.xlsx` and `.html` files.

**Output:**

- Final PDF: `data/Sales_Report_YYYYMMDD_HHMMSS.pdf`

---

### Workflow 2 — AI Agent (`run.py`)

Uses a LangChain ReAct agent (Ollama `deepseek-v4-pro`) to perform flexible analysis based on `config/analysis_requirements.txt`.

```bash
python run.py
```

**What it does:**

- Reads analysis goals from `config/analysis_requirements.txt`.
- Uses tools (`schema_tool`, `pandas_tool`, `matplotlib_tool`, `image_checker_tool`, `typesetting_tool`) to analyze data and generate charts.
- Outputs a Markdown report: `data/Report_YYYY-MM-DD.txt`.
- Moves generated PNG charts into `./data`.

**Configuration:**

- Edit `config/analysis_requirements.txt` to change analysis goals.
- Adjust `config/report_settings.json` for output paths and filename templates.

## Data Input / Output

### Input

| File | Location | Description |
|------|----------|-------------|
| Raw sales data | `data/SGE*.xlsx` | Shipment records (must start with `SGE`). Automatically discovered by `01_find_input.py`. |

Required columns in the raw Excel:

- `Total shipment amount in US$`
- `PO issued month`
- `PO issued year`
- `Product type`
- `Name of end customer`
- `Industry`
- `Order qty`
- `Shipped month`
- `Shipped year`

### Output

| Workflow | Output File | Description |
|----------|-------------|-------------|
| `workflow.py` | `data/Sales_Report_YYYYMMDD_HHMMSS.pdf` | Final branded PDF with tables and Chart.js charts. |
| `run.py` | `data/Report_YYYY-MM-DD.txt` | Markdown text report. |
| `run.py` | `data/*.png` | Charts generated by the agent. |

### Intermediate Files (auto-cleaned)

When running `workflow.py` without `--keep-temp`:

- `data/analysis_YYYYMMDD_HHMMSS.xlsx` — 5-sheet analysis workbook.
- `data/report_YYYYMMDD_HHMMSS.html` — Self-contained HTML report.

## Analysis Logic (`src/logic`)

| Script | Purpose |
|--------|---------|
| `01_find_input.py` | Glob `data/SGE*.xlsx` and print the first match. |
| `02_generate_sheets.py` | Parse raw data → compute achievement rate, YoY comparison, top 5 customers/industries, product summary → write `.xlsx`. |
| `03_generate_html.py` | Read analysis `.xlsx` → generate styled HTML with embedded Chart.js (bar, doughnut charts). |
| `04_export_pdf.py` | Use Playwright to render HTML and print to PDF (A4, with margins). |

---

## Notes

- The deterministic pipeline uses **shipment time** (`Shipped month` / `Shipped year`) as the authoritative time dimension.
- Quarters are defined as cumulative periods: Q1 = Jan–Mar, Q2 = Jan–Jun, Q3 = Jan–Sep, Q4 = Jan–Dec.
- The analysis period is determined by the **last fully completed quarter** relative to the current date.
- Chart axis labels are automatically scaled (e.g., `'k'`, `'M'`) when values exceed 500,000.
